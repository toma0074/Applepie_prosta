## 1. タイトル

【20秒 / 累計0:20】

PROSTAは、プログラミングやIT資格の学習を続けるためのWebアプリです。

キャッチコピーは「解いて終わらない。次の学習につながる。」です。

今日は、困りごとと解決策、デモ動画、そして技術面での挑戦と試行錯誤の順にお話しします。

## 2. 困りごと

【40秒 / 累計1:00】

対象は、プログラミングやIT資格を学び始めた人です。例えば、研修中の新人や学生です。

問題集やWebサイトなど、問題を解く場所はたくさんあります。困るのは、解いたその後です。

一つ目は、何が苦手か分からないこと。

二つ目は、復習する問題を自分で探して管理するのが手間なこと。

三つ目は、一人だと積み重ねが見えず、続かないことです。

つまり、解いた結果が次の行動につながらないことが、本当の困りごとだと考えました。

## 3. 解決策

【45秒 / 累計1:45】

そこでPROSTAは、解く、知る、やり直す、続ける、の流れを一つのアプリにまとめました。

カテゴリや難易度を選んで解き、解答するとすぐに正誤と解説、分野別の正答率が分かります。

復習モードでは間違えた問題を自動で出題し、「弱点から出題」では正答率の低い問題を集めて出題するので、自分で探す必要がありません。

さらに、EXPやレベル、学習カレンダー、仲間の活動で、積み重ねが見えるようにしました。

ブラウザーだけでPCでもスマホでも使え、管理者が問題を追加できるので、実際の学習の場で使える形にしています。

## 4. 独創性（育てる・競う）

【40秒 / 累計2:25】

学習を続けたくなる仕掛けとして、育てる、達成する、競う、の三つを入れました。

正解するとEXPがたまり、相棒キャラクターのスタが卵から成長していきます。結果に合わせて表情や一言も変わります。

毎日のクエストと、積み重ねで解除される実績で、小さな達成感をつくります。

さらに、フレンドの学習の様子や、期間や分野をそろえた友達ランキングで、仲間と刺激し合えます。

今後は、全ユーザーのランキングやフレンド対戦へ広げたいと考えています。これらはまだ構想段階です。

## 7. 技術チャレンジ

【50秒 / 累計7:18】

技術面で挑戦したのは、アプリの中とインフラの両方です。

インフラは、OCIのロードバランサーでHTTPSを受け、VM上のTomcatとOracleデータベースにつなぐ構成を、初めて自分たちで組みました。

アプリでは三つの工夫をしました。

一つ目は、採点からEXP、実績までを一つのトランザクションでまとめて保存し、途中で失敗しても中途半端なデータが残らないようにしたことです。

二つ目は、ブラウザーのタブごとに学習状態を分け、複数のタブで演習しても混ざらないようにしたことです。

三つ目は、同じアカウントで同時にログインされたとき、最後のログインだけを有効にして、データの食い違いを防ぐ仕組みです。

## 8. 試行錯誤

【60秒 / 累計8:18】

試行錯誤した例を三つ紹介します。

一つ目は、本来は404などで返すべきエラーが、500エラーになってしまう問題です。テストを増やしたところ、40件見つかりました。原因はエラー時のトランザクションの取り消しが不十分だったことで、外側でも明示的に取り消すように直し、テストで確認しました。

二つ目は、再読み込みによる二重採点です。採点のPOSTがブラウザーから再送されるのが原因で、採点後はGETの画面へ移動させ、同じタブの処理は順番に実行するようにしました。

三つ目は、本番公開でのHTTPSです。502エラーやリダイレクトの繰り返しが起きました。ロードバランサーとVMの両方で暗号化や転送をしていたのが原因で、暗号化をロードバランサーに集約し、VMはHTTPに統一して整理しました。

※発表前に本番HTTPSの動作を確認し、未解決なら「現在対応中」と言い換えること。
